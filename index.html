I/O 流程

1. 应用程序发起 write()：准备创建临时文件
2. 进入操作系统内核：交给文件系统处理
3. 判断底层设备：SSD/HDD 或 RAMDisk
4. 执行 I/O：慢速磁盘访问或高速 RAM 访问
5. I/O 完成：程序继续运行

小问题：哪个数据最适合放进 RAMDisk？

提示：RAMDisk 适合临时、高频、可丢失的数据。

一句话总结

RAMDisk 的核心是：把原本慢速的磁盘 I/O，变成高速的 RAM 访问，从而减少程序阻塞等待时间。

该实验为课堂可视化模拟，不依赖 Python、Linux、管理员权限或真实 RAMDisk 软件。
